# Cursor command: Mission control

Use when starting or closing a research/engineering cycle.

## Prompt body

```text
Mission control pass (read `.ai-cowork/mission-control.md`):

1. State the single Mission in one sentence.
2. State the single Active Hypothesis (or "none").
3. Confirm one Executor for this session; list read-only reviewers if any.
4. Read Decision Board + stop rules; list violations if any.
5. Output exactly one Next Action.

Lane A lesson: trajectory disagreement is downstream — cite smallest local invariant already checked.
```

## Constraints

- Do not expand scope without updating the mission block.
- Do not merge incompatible contracts in one claim.
